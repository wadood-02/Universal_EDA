# 📊 Universal EDA (Exploratory Data Analysis)

A reusable and automated Exploratory Data Analysis (EDA) notebook built using Python. This project performs comprehensive data analysis on any structured tabular dataset without requiring hardcoded column names or manual modifications.

---

## 🚀 Project Overview

The **Universal EDA** notebook automatically analyzes datasets by detecting numerical and categorical features and generating statistical summaries and visualizations.

It is designed to work with datasets from various domains, including:

- Student Performance
- Healthcare
- Finance
- Sales
- Customer Analytics
- Employee Records
- Retail
- Business Analytics

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/jwadood-02/Universal_EDA.git
```

Move into the project directory:

```bash
cd Universal_EDA
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scipy jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run all cells.
